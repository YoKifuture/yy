# 吸油烟机降噪方案选型与仿真

参赛 Demo 面向评委浏览器。入口放在 `dist/`，整个目录可以原样托管。网页在浏览器内解析频谱、检查约束并筛选侧支亥姆霍兹和微穿孔板；实测频谱文件不会上传。可下载的方案 JSON 记录当前输入、候选结构和初始几何参数。

在项目目录启动预览：

```powershell
py -3.13 -m http.server 8768 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:8768/`。正式交评委时使用已部署网站的 HTTPS 地址。

## 部署到 GitHub Pages

将发布包中的文件上传至自己的 GitHub 仓库。进入仓库 **Settings → Pages**，在 **Source** 中选择 **GitHub Actions**。进入 **Actions → Deploy judging demo**，从默认分支手动运行。部署成功后，在 Pages 页面复制站点地址，填入比赛的「应用展示」。

站点只部署 `dist/`。发布包包含合成频谱、无流样例曲线、计算逻辑与可重建模型的 Java 源码。若需要给代码添加开源许可证，请先确认代码归属，再由权利人选择许可证。

## 验收路径

1. 加载演示样例。频谱为合成数据，目标为 380–460 Hz。
2. 清空开口下限，检查页面是否提示具体缺项。补回 1 mm，确认候选恢复。
3. 将开口下限改为 2 mm，检查微穿孔板进入约束冲突状态。将模块高度改至不超过 65 mm，检查侧挂空间冲突提示。
4. 还原样例，查看空直管与侧支亥姆霍兹的无流传声损失曲线。改变工况或选择微穿孔板后，当前方案回到「待求解」，仍可查看原样例曲线。

## COMSOL 样例复现

运行 `./comsol/run-sample.ps1 -ComsolBin <COMSOL 的 bin/win64 目录>`。脚本在独立任务目录编译 Java 模型并生成直管基准和带侧支腔的模型、曲线与日志。模型是二维等截面压声频域计算，声速 343 m/s，空气密度 1.204 kg/m³，边界为刚壁，进出口采用平面模态端口。模型按 150–950 Hz、5 Hz 间隔扫频，传声损失按入射端口功率与出口透射功率的比计算。模型暂未计入热黏性损耗，因此结果用于无流对比。

跑完后可执行 `node comsol/import-sample.mjs <脚本打印的任务目录>`，核对扫频网格和空直管基准并更新网页曲线。生成的 `.mph` 保存在本项目的 `models/`，供本机复核。

## 大模型与工程工具接入

首选公司「食神 AI」。网页可继续由 GitHub Pages 托管。涉及模型调用时，由公司侧服务负责会话、文件解析、鉴权及工具调用。模型从自然语言提取频段与安装条件，向用户确认缺项，再让工程程序执行计算，最后用计算返回的结果解释推荐。

1. 选型服务复用 `dist/engineering.mjs` 的 `evaluate`、`parseSpectrum` 与 `detectPeaks`。参数与缺项规则由该模块统一维护。
2. 如果食神 Agent 平台支持 HTTP 工具，可把工程选型包装为一个 JSON 接口，配置到工作流内。若平台提供可供外部应用调用的模型或 Agent API，则让网页调用公司后端，再由公司后端发起多轮对话。具体地址、鉴权方式、文件输入与工具调用格式以平台说明为准。
3. COMSOL 端点接收经校验的模板和数值参数，排队运行公司许可的求解节点。任务完成后回传曲线、任务状态和授权可下载的模型。当前 `comsol/run-sample.ps1` 是本机样例验证入口。

GitHub Pages 版本支持浏览器选型和已求解样例。公司大模型接入、Creo 导入、材料仿真模板和网页实时求解后端是后续开发项。Codex 可参与开发和验证，运行时若需要 Codex 类型的工程代理，也可在拥有独立凭据与运行环境的后端接入 Codex SDK。
